# delivery
a simple assignment posting app.

The initial prompt for this was: 
_a 3-tier web app, HTMX, Go and sqlite3; the point of the app is to encapsulate a workflow of adult students who need to submit GitHub repos for various weekly and periodic projects. The student forks and clones a template of a project, they then submit the URL of their solution to the activity (usually a programming project, sometimes a research project). An instructor can then look at the submissions of each student, to review their commits and code. 
there are a list of cohorts (Summer26, Fall26...) and a focus (Java, Data) and then a series of weeks, each week can have one or more project assignments. Each assignment can be an individual assignment, or a group submission. 
Each student and instructor should a GitHub identity (which has been white-listed by a local login admin user. Each instructor can become an admin user)
Each activity has a title, a brief description and a source URL. Also an assigned date, and a final due date.
This app is called "Deliver" (as in what a student or student group) delivers for each assigned activity (programming or research)._
